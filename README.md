# Grocery-Store-Sales-in-SQL

![A_grocery_store_with_neatly_arranged_shelves_stock](https://github.com/user-attachments/assets/ce59bc76-6402-46e1-85f4-15dfa565b4c4)

This project explores and analyzes grocery store sales data using SQL. It was designed to demonstrate data querying, transformation, and insights extraction from a structured dataset relevant to retail operations.

## 📊 Project Overview
The goal of this project is to gain actionable insights from a grocery store's sales data. The analysis covers:

Sales trends over time

Branch performance

Product line performance

Customer behavior

Payment methods and revenue patterns

The project is conducted using SQL queries on a relational dataset and visualized using Jupyter Notebook for clarity.

## 📁 Files Included
grocery_store_sales.ipynb: A Jupyter Notebook containing SQL queries, outputs, and narrative insights.

README.md: Project documentation (this file).

## 🔧 Tools & Technologies
SQL: For data querying and analysis

Jupyter Notebook: For presenting queries and insights in a clean, readable format

SQLite / PostgreSQL (assumed): For running the SQL queries (please specify if different)

## 📌 Key Skills Demonstrated
Writing optimized SQL queries

Grouping, filtering, and aggregating data

Using JOIN, GROUP BY, ORDER BY, and conditional logic

Interpreting business metrics and drawing conclusions

## 📈 Sample Insights
Some of the insights generated through the SQL analysis include:

Top-performing product lines and branches

Most used payment methods

Peak sales days

Customer ratings and their relationship with product categories
